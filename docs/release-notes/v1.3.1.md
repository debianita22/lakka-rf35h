**What's new**

- The kernel is now compiled for the console's CPU (`-mtune=cortex-a35`),
  like the rest of the system already was. Measured on the console against
  the same kernel built without it: message passing between processes in
  the scheduler is 1.8% faster, everything else is unchanged; games won't
  feel different.

Coming from v1.2.0 or earlier: v1.3.0 fixed standby (flickering, slow
console after waking up), brought 162 RetroArch cores instead of 34 and
RetroArch built with link-time optimization; see the
[v1.3.0 notes](https://github.com/debianita22/lakka-rf35h/releases/tag/v1.3.0).
The update is larger than v1.2.0's: see the free space it needs below.
