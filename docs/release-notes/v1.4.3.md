**What's new**

- **Linux 7.2.11** instead of 7.2.9: two stable updates of bug fixes. For
  the console's chip they touch the Rockchip power domains, the display
  bridge (the panel's DSI path), USB OTG and Wi-Fi.
- **39 cores at their newest upstream**, among them Dolphin, PPSSPP, MAME,
  FBNeo, Flycast, Beetle PSX, SwanStation, ParaLLEl N64, Play!, mGBA,
  SameBoy (1.0.4), VBA-M and Stella. The full list is below. Every core of
  the image was opened the way RetroArch does before this release.

If something that worked in v1.4.2 stops working (display, sticks, Wi-Fi,
standby), you can go back: put `TAG=v1.4.2` in
`/storage/.config/rf35h/update.conf` and run System Update, then report it
on the issue tracker. Remove the line to follow the latest release again.

Coming from v1.4.1 or earlier: v1.4.2 made DOSBox, DOSBox-core, ScummVM and
DoubleCherryGB load again, see the
[v1.4.2 notes](https://github.com/debianita22/lakka-rf35h/releases/tag/v1.4.2);
v1.4.1 moved every core to its newest upstream and rebuilt DOSBox on
dosbox-core with additions from DOSBox Pure, see the
[v1.4.1 notes](https://github.com/debianita22/lakka-rf35h/releases/tag/v1.4.1).
