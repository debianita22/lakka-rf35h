**What's new**

- **DOSBox, DOSBox-core, ScummVM and DoubleCherryGB load again.** In
  v1.4.1 RetroArch could not open them ("Failed to open libretro core"),
  and except DOSBox they did not open in v1.4.0 either: they were built
  without libraries they need. DOSBox and DOSBox-core now come with the
  libraries of their MIDI synthesizer (FluidSynth); ScummVM with FluidSynth,
  the Ogg Vorbis file reader and its own AAC decoder; DoubleCherryGB is
  built with its own makefile, which has all of its files. DOSBox is the new
  core described in the v1.4.1 notes.
- **Every core is now opened before a release.** CI loads each core of the
  image the way RetroArch does, and a core that builds but does not load
  stops the release. The weekly core update does the same before moving a
  core to a newer commit.

Coming from v1.4.0 or earlier: v1.4.1 moved every core to its newest
upstream and rebuilt DOSBox on dosbox-core with additions from DOSBox Pure,
see the [v1.4.1 notes](https://github.com/debianita22/lakka-rf35h/releases/tag/v1.4.1);
v1.4.0 updated 131 cores and compiled the kernel for the console's CPU, see
the [v1.4.0 notes](https://github.com/debianita22/lakka-rf35h/releases/tag/v1.4.0).
