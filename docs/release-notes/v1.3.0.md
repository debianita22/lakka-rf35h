**What's new**

- **Standby fixed.** After waking up, the screen no longer flickers and the
  console is no longer slow. The pixel clock of the display now always stays
  on the integer divider of the CPLL (refresh 59.96 Hz); every screen
  power-up after the first used to move it to a fractional divider that left
  the display controller at 3 to 7 frames per second.
- **162 RetroArch cores**: every core Lakka builds for RK3326 that compiles
  here, instead of 34. Many are too heavy for the Cortex-A35 (PlayStation 2,
  GameCube/Wii, 3DS); the
  [guide](https://github.com/debianita22/lakka-rf35h/blob/main/docs/guide.md#cores)
  lists a main core and a fallback for each system.
- RetroArch is now built with link-time optimization, like Mesa and 22
  interpreter cores (3 more than before).
- The update is larger than before: see the free space it needs below.
