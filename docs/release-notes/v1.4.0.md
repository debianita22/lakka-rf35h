**What's new**

- **Cores updated.** 131 of the 162 RetroArch cores now come from the newest
  commit of their upstream that compiles here, instead of the versions Lakka
  had pinned in May; the full list is below. The others keep the version they
  had: 22 because their newest upstream does not compile here yet (among
  them Mupen64Plus-Next, ParaLLEl N64, Flycast, FBNeo and Beetle PSX), the
  rest because their upstream has not moved. From now on every release ships
  the cores at their newest commit that compiles; there are no separate core
  updates.
- The kernel is compiled for the console's CPU (`-mtune=cortex-a35`), like
  the rest of the system already was. Measured on the console against the
  same kernel built without it: message passing between processes in the
  scheduler is 1.8% faster, everything else is unchanged; games won't feel
  different.
- SameBoy is built with the system's compiler flags and link-time
  optimization: its own Makefile used to discard them.

Coming from v1.2.0 or earlier: v1.3.0 fixed standby (flickering, slow
console after waking up), brought 162 RetroArch cores instead of 34 and
RetroArch built with link-time optimization; see the
[v1.3.0 notes](https://github.com/debianita22/lakka-rf35h/releases/tag/v1.3.0).
The update is larger than v1.2.0's: see the free space it needs below.
